# Vinted Automation Platform

Private TypeScript monorepo for Vinted marketplace research, normalized domain models and future automation workflows.

This repository is in Phase 0 foundation work. Vinted write/private endpoints are research-gated and must not be guessed.

## Scripts

- `npm run typecheck`
- `npm run lint`
- `npm test`

## Workspace Packages

- `@vinted-bot/domain`: internal product/domain types.
- `@vinted-bot/vinted-client`: Vinted-specific session, transport and diagnostics boundaries.
